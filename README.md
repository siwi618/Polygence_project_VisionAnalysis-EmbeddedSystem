# Polygence_project_VisionAnalysis-EmbeddedSystem
This project aims to improve immersive experience of users in museum. In the past, most museums would provide a guide for a group of visitors. However, considering the time limitation and the different exhibits people may be interested in, every visitor wouldn't get a very immersive experience for themselves. To let every visitor get an idealised experience, I will build a small local image classification model that could recognize specific exhibits in real time, comparing it with MobileNet finally.
